# Security Policy

This repository contains follow-along lab guides, scripts, and queries for a cloud SOC built in a personal Azure lab. It is not production software and has no supported releases.

## Reporting an issue

If you find something sensitive that should not be public, such as a credential, a real IP address or hostname, or personal information, please report it privately:

1. Open the **Security** tab of this repository.
2. Select **Report a vulnerability**.
3. Describe what you found and where (file and line, or commit).

Please do not open a public issue for sensitive findings. I aim to acknowledge reports within 7 days.

## Scope

- In scope: exposed secrets or personal data, and scripts or queries that would be unsafe to run as written.
- Out of scope: findings in the intentionally insecure lab VMs described in the guides, which were exposed on purpose to generate attack telemetry and have since been deleted.
